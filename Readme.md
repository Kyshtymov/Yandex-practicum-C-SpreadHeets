# 📊 Электронная таблица

Упрощённый аналог Microsoft Excel и Google Sheets на C++: таблица с текстовыми и формульными ячейками, поддержкой ссылок между ячейками, кэшированием и обработкой ошибок.

---

## 📋 Описание

Программа реализует лист электронной таблицы, в ячейках которого может находиться текст или формула. Формулы поддерживают арифметические операции, скобки, числа и ссылки на другие ячейки (`=A1*3+4/B2`). Для вычисления формул используется собственная грамматика на **ANTLR**, а результаты кэшируются для повышения производительности.

Проект создавался в три этапа: сначала упрощённая таблица без ссылок, затем проектирование дизайна классов, и наконец — полная реализация с графом зависимостей, кэшем и обработкой исключений. Это позволило на практике применить принцип «сначала дизайн, потом код».

---

## ✨ Возможности

- 📝 **Текстовые ячейки** — простое хранение строк, экранирование через апостроф `'`
- 🧮 **Формульные ячейки** — начинаются со знака `=`, содержат числа, скобки и арифметические операции
- 🔗 **Ссылки на ячейки** — формулы могут ссылаться на другие ячейки (`=A1+B2*C3`)
- 🚫 **Обнаружение циклических зависимостей** — при попытке создать цикл выбрасывается `CircularDependencyException`
- ⚡ **Кэширование значений** — повторное вычисление неизменённой формулы не требуется
- 🔄 **Инвалидация кэша** — при изменении ячейки пересчитываются все зависимые от неё
- ⚠️ **Обработка ошибок** — `#ARITHM!`, `#VALUE!`, `#REF!` с распространением вверх по зависимостям
- 🖨️ **Печать таблицы** — вывод текстов или значений ячеек в минимальной печатной области
- 📐 **Поддержка ANTLR** — грамматика формул описана в `Formula.g4`

## 🚀 Сборка и запуск

### Требования

- Компилятор с поддержкой **C++17**
- **CMake 3.5+**
- **JDK** (для запуска ANTLR)
- **ANTLR 4.13.2** — JAR-файл (`antlr-4.13.2-complete.jar`)
- **ANTLR C++ Runtime** — содержимое архива `antlr4-cpp-runtime*.zip` в папке `antlr4_runtime/`

### Структура для сборки

```
spreadsheet/
├── antlr4_runtime/                    # Содержимое antlr4-cpp-runtime*.zip
├── antlr-4.13.2-complete.jar          # JAR ANTLR
├── CMakeLists.txt
├── FindANTLR.cmake
├── Formula.g4
└── ... остальные файлы проекта
```

### Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

Сгенерированные ANTLR файлы появятся в `build/antlr4cpp_generated_src/Formula/`.

### Запуск

```bash
./spreadsheet
```

Программа выполняет набор unit-тестов и выводит результат в `stdout`.

## 🏗️ Архитектура


```
┌──────────────────┐
│      Sheet       │  ← хранит ячейки, граф зависимостей
│  cells_          │
│  backward_refs_  │
└────────┬─────────┘
         │ содержит
         ▼
┌──────────────────┐
│       Cell       │  ← обёртка над Impl, кэш значения
│   impl_          │
│   cache_         │
└────────┬─────────┘
         │ делегирует
         ▼
┌──────────────────────────────┐
│            Impl              │  ← абстракция типа ячейки
├──────────────┬───────────────┤
│  EmptyImpl   │   TextImpl    │
├──────────────┴───────────────┤
│        FormulaImpl           │  ← хранит FormulaInterface
└──────────────────────────────┘
         │ использует
         ▼
┌──────────────────┐
│     Formula      │  ← парсит и вычисляет выражение
│      ast_        │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│    FormulaAST    │  ← AST, построенный ANTLR
└──────────────────┘
```

### Ключевые решения

- **Паттерн «Стратегия»** — класс `Cell` делегирует поведение одной из реализаций `Impl` (Empty, Text, Formula). Это позволяет менять тип ячейки без изменения самого `Cell`.
- **Граф зависимостей** — `Sheet` хранит обратные ссылки `backward_references_`: для каждой ячейки — множество ячеек, которые от неё зависят. Это нужно для инвалидации кэша и поиска циклов.
- **Кэш на уровне ячейки** — `Cell::cache_` хранит последнее вычисленное значение. Если ни одна из зависимостей не изменилась, повторное вычисление не выполняется.
- **Инвалидация кэша** — при изменении ячейки рекурсивно пересчитываются все зависимые ячейки, каждая — только один раз.
- **Проверка циклов до записи** — перед `SetCell` строится временная ячейка и проверяется, не создаст ли она цикл. Если да — выбрасывается исключение, а таблица не меняется.
- **Разбор формул через ANTLR** — грамматика `Formula.g4` описывает выражения с числами, скобками, операциями и индексами ячеек. ANTLR генерирует лексер и парсер, поверх которых строится AST.

## 🧪 Тестирование

В `main.cpp` реализован набор unit-тестов, покрывающих:

- Преобразование `Position` ↔ строка
- Установку и очистку ячеек
- Вычисление формул с числами и ссылками
- Форматирование выражений
- Обработку ошибок (`#VALUE!`, `#ARITHM!`, `#REF!`)
- Циклические зависимости
- Печать таблицы
- Пустые ячейки и ячейки за границами таблицы

Тесты запускаются автоматически при старте программы.

## ⚠️ Обработка ошибок

| Исключение | Когда выбрасывается |
|---|---|
| `InvalidPositionException` | Некорректная позиция (`row < 0`, `col < 0`, выход за `MAX_ROWS`/`MAX_COLS`) |
| `FormulaException` | Синтаксически некорректная формула (`=A1+*`) |
| `CircularDependencyException` | Формула создаёт циклическую зависимость |

**Ошибки вычисления** (не исключения) возвращаются как `FormulaError`:

| Код | Причина |
|---|---|
| `#ARITHM!` | Деление на ноль, переполнение |
| `#VALUE!` | Ячейка не может быть проинтерпретирована как число |
| `#REF!` | Ссылка на ячейку за границами таблицы |

Ошибки **распространяются вверх по зависимостям**: если `C2` содержит `#VALUE!`, то `C4 = C2 + 8` тоже вернёт `#VALUE!`.
